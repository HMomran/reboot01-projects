# Real-Time Forum

## Project Structure

```
real-time-forum/
├── frontend/
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   ├── init.js
│   ├── Chat.js
│   ├── Login.js
│   ├── Registration.js
│   ├── Posts.js
│   └── PostDetail.js
└── backend/
    ├── main.go
    ├── go.mod
    ├── db/
    ├── handlers/
    ├── models/
    └── uploads/
```

## How to Start

```bash
cd backend
go run .
```

Open **http://localhost:5500** in your browser.
